# 事業性・法規制の検討

版：v0.6／更新日：2026-09-21  
位置付け：開発手順ではなく、事業として成立させるための前提と制約を扱う。
開発計画書（`plans/01`〜`plans/06`）とは更新の周期が異なるため分離する。

ここに書かれた料金・費用・区分はいずれも検討中の想定であり、確定した事業計画ではない。

## 1. 法規制上の留意点

- 独自に加工した気象の予想を発表することは、気象業務法上の予報業務許可を要する
  可能性がある。気象庁または予報業務許可を持つ事業者の予報値をそのまま引用する形に
  留める。有料プランの「事前警告」がこれに該当しないか確認を要する
- 「発生予察情報」は植物防疫法に基づき都道府県が発表するものである。同一の名称を
  避け、参考情報であることを明示する
- メッシュ農業気象データを加工した判定結果を、自社サービスの契約者へ提供する形態が
  許諾範囲に含まれるかを確認する。製造元は株式会社ライフビジネスウェザー
  （予報業務許可83号）である
- 無償ライセンス（研究・開発・教育・試用）で取得したデータを、商用サービスの閾値検証に
  用いてよいかを確認する

## 2. 事業性の前提

### 2.1 料金モデル

- 家庭菜園層：無料（地域登録のみ、作物登録不可、病害虫は条件成立後の事後通知）
- 有料（月200〜300円想定）：作物登録可、条件到達前の事前警告、圃場記録
- 農家向け：最初から有料

### 2.2 広告収入は見込まない

無料層に広告を載せても金額が合わない。本アプリの適切な使い方は1日1回の確認であり、
滞在時間を伸ばす設計は農家にとって邪魔になる。また作物登録できない無料層は
ターゲティング材料が乏しく、農業資材の広告主にとって価値が低い。

金額以上に、病害虫の警告画面に資材広告が並ぶことによる信頼の毀損が問題となる。
判定の根拠を提示する設計と衝突する。

無料層は収益源ではなく、有料転換の導線として設計する。

### 2.3 費用構造

メッシュデータを契約する場合、5要素で月16,500円・年198,000円が固定費となる。
いちご（9月〜5月）と水稲（4月〜9月）を合わせても、利用者個人から見た価値は半年程度
であり、実効課金月数は年6〜8ヶ月と見る。

### 2.4 検証サイクル

栽培暦に縛られるため、ルールの検証機会は年1回である。閾値の調整に年単位を要する。
改善速度に構造的な上限があるが、同時に参入障壁でもある。

## 3. 確認中の事項

外部への確認が必要で、結果によって設計が変わるもの。

| 項目 | 窓口 | 影響 |
|---|---|---|
| 加工結果をエンドユーザーへ提供する形態の可否 | ビジョンテック経由でライフビジネスウェザー | 事業成立の可否 |
| 1気象要素/月3,300円は全国固定か取得量課金か | ビジョンテック | 料金モデルの成否 |
| WebAPIのリクエスト回数・取得範囲の制限 | ビジョンテック | アーキテクチャ |
| 過去データのバックフィルの課金計上 | ビジョンテック | 新規契約時の運用 |
| バッチ処理用トークンの発行可否 | 農研機構（sh-meshadmin@naro.go.jp） | 無償ルートの自動化可否 |
| 無償ライセンスの検証利用の範囲 | 農研機構 | 開発フェーズの進め方 |
| APCPRAの平年値がどの系列で作成されているか | 農研機構 | 平年比判定の妥当性 |
| WAGRI利用料の会員区分による差 | 農研機構 | 費用比較 |
